## Week 4 / Network forensics

This week focuses on evidence-led analysis of network traffic. Work through the overview first, then open each task from the course navigation.

### Sequence

1. Read the packet-trace task and isolate the unusual exchange.
2. Complete the guided analysis checkpoints.
3. Submit the finding in flag form.

The task list is generated from the files in this week folder, so adding another task file automatically adds it to the course navigation.
